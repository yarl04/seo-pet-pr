# Ручная проверка доступности

Этот список дополняет Playwright и axe-core. Проверку реальным скринридером нужно выполнять отдельно; автоматические тесты её не заменяют.

## Клавиатура

- [ ] Открыть главную, нажать Tab. Первой появляется ссылка «Перейти к содержимому»; Enter переводит фокус в main.
- [ ] Пройти шапку и карточки по Tab/Shift+Tab. Фокус различим, порядок соответствует чтению страницы, ловушек нет.
- [ ] В каталоге найти «паста», затем ограничить время до 20 минут. Остаётся паста с томатами.
- [ ] В поле «Основной ингредиент» набрать «кур», нажать ArrowDown и Enter. Выбрана «Курица», показан соответствующий рецепт.
- [ ] Открыть варианты стрелкой, исследовать их, нажать Escape. Подтверждённый выбор не изменяется.
- [ ] Ввести другой текст и нажать Tab без выбора. Список закрывается, поле возвращает подтверждённый ингредиент, фокус переходит к фильтру времени.
- [ ] Снять фильтр очисткой поля. Проверить полный сброс, пустой результат и возврат из рецепта кнопкой браузера «Назад».

## Скринридер

Проверить минимум NVDA + Firefox/Chrome либо VoiceOver + Safari. Записать версии браузера и скринридера и фактические результаты.

- [ ] Перемещаться по landmarks средствами скринридера (NVDA: D/Shift+D; VoiceOver: ротор). Есть banner, именованные navigation, main и contentinfo; complementary объявляется только там, где есть совет.
- [ ] У основного меню и хлебных крошек различимые названия. Вложенный header рецепта не объявляется второй шапкой сайта.
- [ ] Навигация по заголовкам: один h1, далее h2 разделов и h3 вложенных элементов.
- [ ] Ингредиенты и последовательность приготовления объявляются списками с количеством элементов. Шаги читаются в правильном порядке.
- [ ] Комбобокс объявляет имя, значение, раскрытое/свёрнутое состояние. При движении стрелками читается активная подсказка, фокус остаётся в поле.
- [ ] При изменении фильтров объявляется новое количество рецептов. Ноль результатов понятен без визуального просмотра.
- [ ] У содержательных фотографий уместный alt. Декоративные стрелки, таймер и дублирующие миниатюры не озвучиваются.

Обычный Tab проходит интерактивные элементы, а не landmarks. Перемещение по областям проверяется командами скринридера.

## Визуальные и альтернативные режимы

- [ ] Масштаб 200–400% и ширина 320 CSS px: текст не обрезан, элементы доступны, горизонтальная прокрутка отсутствует.
- [ ] При reduced motion переходы отключены.
- [ ] В режиме forced colors видны границы полей и фокус.
- [ ] При отключённом JavaScript доступны все рецепты, категории, ингредиенты и шаги; есть пояснение о фильтрах.
- [ ] В печатном предпросмотре остаются рецепт, ингредиенты, шаги и совет.

Ориентиры: [landmarks](https://www.w3.org/WAI/ARIA/apg/practices/landmark-regions/), [combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/), [пример редактируемого комбобокса](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-autocomplete-list/), [декоративные изображения](https://www.w3.org/WAI/tutorials/images/decorative/).
